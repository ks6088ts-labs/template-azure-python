# template-azure-python

This repository is a template for Python projects. Use these guides to develop,
run, and deploy the included FastAPI application and Microsoft Foundry samples.

## Guides

- [Scripts and development](scripts.md): prerequisites, Make targets, Python
  CLI commands, local servers, and Docker workflows.
- [Deployment](deployment.md): Azure Functions, Azure Container Apps, Docker
  Hub, and Azure Static Web Apps.
